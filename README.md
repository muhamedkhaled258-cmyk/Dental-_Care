# 🦷 Dental Care – Premium Dental Clinic Portfolio Website

A modern, high-end, and visually stunning single-page dental clinic portfolio website built with HTML, CSS, and JavaScript.

---

## ✅ Completed Features

### 🌐 Bilingual Support (EN / AR)
- Full English ↔ Arabic language switching via navbar toggle
- RTL layout automatically applied for Arabic
- Poppins font for English, Cairo font for Arabic
- All sections, buttons, labels, and form fields translated
- Smooth transitions between languages

### 🏠 Hero Section
- Full-screen clinic background image with parallax-style loading
- Soft dark gradient overlay for readability
- Clinic name, tagline, and supporting line (bilingual)
- Three CTA buttons: Book Now (scroll), Call Us (click-to-call), WhatsApp
- Animated stats bar (20+ years, 5K+ patients, 15+ specialties)
- Scroll-down indicator with animation
- AOS entrance animations

### 👨‍⚕️ About the Doctor
- Doctor profile photo with hover zoom
- Name, university, and experience badge
- Specialization tags with hover effects
- Certifications & memberships list
- Decorative animated circle element

### 🦷 Services Section (6 Cards)
- 3-column grid with hover image zoom
- Overlay CTA button on hover
- Service icon, title, and description
- Services: Fillings, Fittings, Implants, Orthodontics, Pediatric, Root Canal

### 📸 Before & After Slider
- 5 transformation images
- Auto-advancing slider (4.5s interval)
- Prev/Next arrow buttons
- Dot navigation
- Touch/swipe support for mobile
- Before/After labels on image

### 🎥 Video Highlights
- 3 YouTube Shorts embedded with autoplay + mute
- Dark premium background section

### 📅 Booking Form
- Full Name, Phone, Service dropdown, Message
- WhatsApp pre-filled message with user data
- Info panel: hours, address, phone, WhatsApp
- Form validation with toast notification

### 📍 Location Section
- Embedded Google Maps
- Address, working hours, phone details
- "Open in Maps" link button
- "Get Directions" CTA

### 🔻 Footer
- Brand, Quick Links, Contact columns
- Social icons: WhatsApp, Phone, Facebook, Instagram
- Working hours, full address

### ➕ Extra Features
- **Page loader** with animated progress bar
- **Sticky WhatsApp button** with pulse animation + tooltip
- **Active nav link highlighting** on scroll
- **Navbar scroll effect** (transparent → white with blur)
- **AOS scroll animations** throughout all sections
- **Image shimmer loader** (skeleton loading state)
- **Mobile hamburger menu**
- **Toast notifications** for form feedback
- **Custom scrollbar** styling
- **Responsive** on all screen sizes
