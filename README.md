## Overview

Dental Care is a premium single-page dental clinic website designed to deliver
a polished and professional digital experience for both English and Arabic users.

The project goes beyond a static landing page.

It combines:

- Bilingual content management
- Automatic RTL / LTR layout switching
- Interactive navigation
- Smooth scroll behavior
- Animated UI elements
- Before & After sliders
- Booking functionality
- WhatsApp integration
- Embedded Google Maps
- Responsive layouts
- Loading states
- Form validation
- Mobile navigation

The goal is to create a frontend experience that feels closer to a real
production website than a simple portfolio template.

## Features

### Bilingual Experience

The website supports both English and Arabic.

| Capability | Description |
|---|---|
| Language Switching | Switch between English and Arabic |
| RTL Support | Arabic automatically applies RTL layout |
| Typography | Poppins for English and Cairo for Arabic |
| Dynamic Content | Text content updates based on selected language |
| UI Direction | Layout alignment changes automatically |
| Navigation | Navigation remains functional in both languages |

The language system is designed to provide a natural experience rather than
simply translating text.

---
