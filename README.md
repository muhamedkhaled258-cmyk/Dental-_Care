## Overview

Dental Care is a premium single-page dental clinic website built with a strong
focus on modern UI/UX, responsive design, accessibility, animations, and
interactive user experiences.

The website supports both English and Arabic users and automatically adapts
its layout direction when switching between LTR and RTL languages.

The project is designed to feel like a real production website rather than
a simple static landing page.

---

## Main Features

### Bilingual Experience

The website provides a complete English and Arabic experience.

- English and Arabic language support
- Dynamic content translation
- Automatic LTR and RTL layout switching
- Arabic-friendly typography
- Navigation support for both languages
- Smooth language transition
- Responsive bilingual interface

---

## Navigation System

The navigation system is designed to remain accessible and informative
throughout the browsing experience.

### Navigation Features

- Sticky navigation bar
- Smooth scrolling between sections
- Active section detection
- Active navigation indicator
- Scroll-based navigation state
- Section-based navigation
- Mobile responsive navigation
- Mobile hamburger menu
- Language switcher
- Navigation state transitions

The main navigation provides access to:

- Home
- About
- Services
- Results
- Videos
- Book Appointment
